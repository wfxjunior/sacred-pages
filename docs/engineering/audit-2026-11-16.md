# Lumena audit — 2026-11-16

## Verified
- All 653 existing tests passed across 35 files (games, puzzle generation, journey state, content, plans and authentication services).
- 23 primary pages returned HTTP 200 with no captured browser exceptions, using the injected authenticated session. Opening a page is not equivalent to verifying all of its actions.
- Home, collections, donation, Today and Word Guess had no document-level horizontal overflow at 390px width.
- Today's devotional labels translated into Portuguese and Spanish; hide/show controls worked and no raw `journey.story` or `today.showPanel` text appeared.
- Basic security scan completed with two informational public-read notices for language and milestone translation catalogs. No critical findings in that basic scan. Deep security analysis was started separately and remains pending.

## Confirmed problems — not changed by this audit
1. **High: Word Search progress does not survive reload.** A real word selection produced five selected cells and persisted `found: ["NEVER"]`. Reload changed the puzzle session from `s1` to `s2`, produced a different word list, and displayed zero selected cells. The previous storage entry was also overwritten with an empty found list. `/today` advances its draw/session on every mount, and the WordSearch persistence cleanup can write fresh state under the old key. Resume must preserve the active puzzle identity and the writer must retain key-specific state. Existing passing tests do not cover this UI integration.
2. **Desktop puzzle layout:** At 1280×1800, the puzzle was very small beside a full-height word rail. The layout needs verification at common desktop heights before a focused adjustment.
3. **Incomplete localization:** The reflection textarea has a hard-coded English placeholder. Translation dictionaries contain the recent devotional keys, but no automatic used-key validation is registered in the build configuration or package scripts.
4. **PWA offline behavior:** A manifest and icons exist, but no service-worker registration was found. Offline operation and installation prompts were not verified on physical devices.
5. **Page metadata:** Several content pages rely on shared metadata instead of declaring their own complete social metadata; game and administration pages are among them.

## Security and performance review items
- Database advisor reported 11 elevated-function execution warnings and 61 performance notices. These are review signals, not 11 confirmed vulnerabilities. Inspected progress/milestone routines check the caller; invitation preview intentionally supports token-based public access and suppresses anonymous email disclosure. Full live-function authorization review is still pending the deep scan.
- The performance notices include 41 unindexed foreign keys; no database changes were made.

## Not verified
- Charging a payment, Stripe webhook delivery, receipt of emails, Google OAuth round-trip, sending/accepting a real invitation, uploading an avatar, and writing persistent account settings.
- No payments were initiated and no messages were sent. Puzzle selections changed browser-local state only.

## Maintenance
- Applied the required TanStack security version update and adapted the root error-boundary props to the framework's current type without changing behavior.
